# Lebanon locations v2: validation report

Generated by `npm run locations:v2` (scripts/build-locations-v2.mjs). Sources: CAS settlements list and HDX COD-AB boundaries (the official data of v1), **OpenStreetMap** (Overpass API, snapshot 2026-11-25), **GeoNames** (LB dump), and a short hand-made list of well-known neighbourhoods. Every place is assigned to its district by point-in-polygon against the official COD-AB district boundaries.

## Totals

- Official regions (CAS, v1): **2708**
- Regions after v2: **4241** (+1533)
- Source rows read: OSM 1911, GeoNames 3712 (populated places only), manual 102
- Merged into an existing region (alias added): OSM 1651, GeoNames 2436, manual 98
- Added as new regions: OSM 256, GeoNames 1273, manual 4
- Outside Lebanon's district polygons (skipped): OSM 2, GeoNames 3
- Regions that gained aliases: 2070; total aliases: 3899

- Low-confidence assignments: **118** (`docs/locations-v2/low_confidence.csv`)
- Same-name places told apart: 60; new places with no English name (Arabic shown): 62
- Validation errors: **0**

## Where to look (full lists)

- `docs/locations-v2/new_places.csv`: places found in OpenStreetMap / GeoNames / by hand that are NOT in the official list (added as new regions).
- `docs/locations-v2/official_not_found_elsewhere.csv`: official regions that neither OSM nor GeoNames confirm.
- `docs/locations-v2/merges.csv`: duplicates merged into one region, with the names kept as aliases.
- `docs/locations-v2/fuzzy_merges.csv`: merges decided on a spelling variant or on proximity only (review these first).
- `docs/locations-v2/low_confidence.csv`: places near a district boundary or whose sources disagree about the district.
